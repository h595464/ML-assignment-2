# Mushroom Toxicity Classifier

A small machine learning project that predicts whether a mushroom is **edible or poisonous** from its physical characteristics. A Random Forest model is trained on the UCI Mushroom dataset and served through a simple Flask web app.

> **Disclaimer:** This is an educational project. Never use it to decide whether a wild mushroom is safe to eat. Misidentification can be fatal.

## Dataset

[UCI Machine Learning Repository: Mushroom (ID 73)](https://archive.ics.uci.edu/dataset/73/mushroom)

- About 8,000 mushroom samples
- 22 categorical features (odor, cap color, gill size, etc.)
- Target: `e` (edible) or `p` (poisonous)

The data is downloaded automatically with the `ucimlrepo` package when you run the training script.


## Setup

**Requirements:** Python 3.11 or newer is recommended (the pinned pandas and NumPy versions need a recent Python).

1. Create and activate a virtual environment:

   Windows:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   ```

   Mac/Linux:
   ```
   python3 -m venv .venv
   source .venv/bin/activate
   ```

2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

## Usage

1. **Train the model** (only needed once):
   ```
   python train_model.py
   ```
   This prints a classification report and creates `model.joblib` and `options.json`.

2. **Start the web app:**
   ```
   python app.py
   ```

3. Open http://127.0.0.1:5000, choose a value for each feature, and click **Classify**.

## How It Works

1. `train_model.py` fetches the dataset, fills missing values (`stalk-root`) with `?`, and splits the data 80/20 with stratification.
2. A scikit-learn pipeline one-hot encodes the categorical features and trains a `RandomForestClassifier` (100 trees).
3. The trained pipeline and the valid options for each feature are saved to disk.
4. `app.py` loads them, builds the form dynamically from `options.json`, and returns a prediction with a confidence percentage.

## Notes

- The form dropdowns show the dataset's single-letter codes (for example, odor `a` = almond, `n` = none, `f` = foul). Meanings are listed under "Variables" on the dataset page.
- Expect near-100% accuracy. This dataset is very easy to separate (odor alone is a strong predictor), so the result will not carry over to real-world mushroom identification.

## Troubleshooting

- **`fetch_ucirepo` fails:** Check your internet connection, or download the CSV manually from the dataset page and load it with `pandas.read_csv` in `train.py`.
- **`FileNotFoundError: model.joblib`:** Run `python train_model.py` before `python app.py`.
